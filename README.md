# apurvtaneja/tap

Homebrew casks by [@apurvtaneja](https://github.com/apurvtaneja).

## Dictator

Press a hotkey anywhere on your Mac and speak; clean, punctuated text is typed where your
cursor is. See [apurvtaneja/dictator](https://github.com/apurvtaneja/dictator).

```sh
brew install --cask apurvtaneja/tap/dictator
```

Dictator isn't notarized by Apple yet, so the first launch needs one click: System Settings →
Privacy & Security → **Open Anyway**.

Upgrade with `brew upgrade --cask dictator`. Remove with `brew uninstall --cask dictator`;
add `--zap` to also delete its settings in `~/.config/dictator`.
